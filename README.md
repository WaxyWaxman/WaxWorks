# WaxWorks
Vinyl Records a la carte

Point-of-sale and inventory management for independent vinyl record stores.

## Documentation

See [`docs/`](docs/) — start with the [documentation index](docs/README.md) or go straight to the [PRD](docs/PRD.md).

The project is in the requirements phase; there is no application code yet.

## Planning agent

Requirements and architecture work is driven by shared Claude Code skills in
[`.claude/skills/`](.claude/skills/) — `/flow-clarify`, `/flow-new`, `/architecture`,
`/spec-audit`. They are checked into the repo so every contributor gets the same
behaviour. Conventions live in [CLAUDE.md](CLAUDE.md); the clone-to-pull-request
workflow is in [CONTRIBUTING.md](CONTRIBUTING.md).
