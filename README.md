# WaxWorks
Vinyl Records a la carte

Point-of-sale and inventory management for independent vinyl record stores.

## Documentation

See [`docs/`](docs/) — start with the [documentation index](docs/README.md) or go straight to the [PRD](docs/PRD.md).

The project is in the requirements phase. A [clickable prototype](prototype/) of the
counter-core flows exists for reviewing screens and flows — see
[`docs/prototype.md`](docs/prototype.md). There is no production application code yet.

## Planning agent

Requirements, architecture, and QA work are driven by shared Claude Code skills in
[`.claude/skills/`](.claude/skills/) — `/plan-check`, `/flow-clarify`, `/flow-new`,
`/architecture`, `/qa`, `/spec-audit`. They are checked into the repo so every
contributor gets the same behaviour. Conventions live in [CLAUDE.md](CLAUDE.md); the
clone-to-pull-request workflow is in [CONTRIBUTING.md](CONTRIBUTING.md).
